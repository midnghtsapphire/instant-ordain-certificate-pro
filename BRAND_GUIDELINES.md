# Brand Guidelines

## Brand stack
- Product: Instant Ordain Certificate Pro
- Frontend brand: SmartMinisterBot
- Church authority reference: EverUnity Church

## Voice
- reassuring
- legally aware without sounding like legal advice
- fast, modern, and conversion-oriented
- respectful across Christian, interfaith, spiritual, and nature-based ceremony contexts

## Messaging priorities
1. speed: become ordained quickly
2. legitimacy: church-backed credentials and state-aware ceremony support
3. flexibility: inclusive certificate paths for multiple ceremony styles
4. confidence: clear pricing, instant delivery, and premium upgrades

## Visual direction
- keep the gold / amber and blue church palette already present in the UI
- use certificate previews and seals as trust-building assets
- preserve a premium, ceremonial feel rather than a generic SaaS look

## Naming usage
- use `Instant Ordain Certificate Pro` for repository, deployment, and product documentation
- use `SmartMinisterBot` inside user-facing marketing copy where the current UI already does so
- keep `EverUnity Church` as the ecclesiastical authority reference, not the primary software product name
